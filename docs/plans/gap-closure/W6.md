# W6: switching regulators (G21)

Branch `w6-switching-regulators`, base 92de07e (wave-1 tip).

## What was built

Four generic packages under `app/library/electrical/` (subcategory Regulators), one shared model file
`app/library/_models/power/pwm_avg.lib` (record appended to `_models/MANIFEST.toml`):

| id | pins | model |
|---|---|---|
| `BUCK_AVG` | vin, gnd, out | CCM averaged buck, fixed duty `D`, inductor `L` and series resistance `RL` inside |
| `BUCK_AVG_CTL` | + ctl | duty = `D` + V(ctl) (1 V = 100 %), for AC control-to-output and feedback loops |
| `BOOST_AVG` | vin, gnd, out | CCM averaged boost, fixed `D` |
| `BOOST_AVG_CTL` | + ctl | same with the duty input |

The model is the Vorperian PWM switch (period-averaged switch and diode): buck `v(sw) = d v(vin)`, current from vin
`d iL`; boost `v(sw) = (1-d) v(out)`, current into out `(1-d) iL`. The output capacitor and load are external parts.
All four validate as `full` (no `limited` status, 0 errors, 0 warnings in `python3 -m app.catalog`). They declare
`live = []` (an instance parameter cannot be changed soundly during a live run), `verification = "analytic"`,
`model_kind = "equivalent"`, provenance citing Erickson and Maksimovic, *Fundamentals of Power Electronics*.

No named IC (LM2596 style) was added: there is no way here to check it against datasheet curves (efficiency, ripple
and load transient curves depend on the switching frequency, DCM and diode loss, none of which an averaged model has).

## Findings that shaped the model

- `gnd` as a `.subckt` port name is rejected: ngspice treats it as the global ground alias. The core uses `rt`.
- The validator flags a B source that reads its own output node pair (`B-SELFREF`). The B sources therefore drive `rt2`,
  which is `rt` through a 0 V source, and read `V(.,rt)`.
- The fixed-duty wrappers hold the unused `ctl` node at `rt` through a 0 V source, to avoid a DANGLING warning.
- `RL` has `min_exclusive` 0 (a 0 ohm resistor is invalid in a deck); the checks use 1 uohm.

## Checks (all in `app/tests/test_switching_regulators.py`, through Document -> app.sim -> ngspice)

| check | analytic | result |
|---|---|---|
| buck DC ratio, D 0.25 and 0.8 | `D Vin` | within 2e-4 relative (D 0.8: 9.599998 V vs 9.6 V) |
| boost DC ratio, D 0.25 and 0.6 | `Vin/(1-D)` | within 2e-4 (D 0.6: 29.99996 V vs 30 V) |
| conduction-loss efficiency, RL 0.5 ohm | buck `R/(R+RL)`; boost `1/(1+RL/(D'^2 R))`, and the matching Vout | within 2e-4 |
| load-current step 1 -> 3 A (buck), 0.5 -> 1 A (boost), from a cold start | averaged ODE integrated by scipy (Radau, rtol 1e-10); buck also closed-form steady states before and after | within 1 % of the step size; steady states within 5 mV |
| buck AC line-to-output and control-to-output | `D/(1+sL/R+s^2 LC)`, `Vin/(...)`, 10 Hz to 100 kHz | max relative error 1e-5 (complex, magnitude and phase); peak at the LC resonance (1591.5 Hz), Q = 10 |
| boost AC line-to-output | `(1/D')/(1+sL/(D'^2 R)+s^2 LC/D'^2)` | max relative error 1e-5 |
| boost AC control-to-output | `(Vg/D'^2)(1 - sL/(D'^2 R))/(...)`, RHP zero at 3978.9 Hz | max relative error 1e-5; the phase of numerator alone lags by `atan(f/fz)` at fz (a left-half-plane zero would lead) |

The transient reference for the load step is the same averaged equations, so it checks the implementation and
integration, not the averaging approximation; the averaging assumption is covered by the cited formulas (and by the
AC checks, which are the textbook small-signal results).

## Limitations stated in each package

No switching ripple or frequency; no switching, diode or core loss (efficiency is the series-resistance conduction loss
only); DCM not modelled (light load drives the averaged inductor current negative, as a synchronous converter does, which
`test_dcm_is_not_modelled_...` pins); no duty, current or voltage limit and no soft start; small-signal AC valid only
well below the switching frequency; parameters are not live-adjustable.

## Proposed GAPS row

G21: partially fixed. Averaged generic CCM buck and boost (with and without a duty input) are in and checked against
the analytic DC, efficiency (conduction loss), load-step and AC small-signal values. A named switcher IC, switch-level
ripple, DCM and switching-loss efficiency are not done: they need a switch-level model with a datasheet to check it.
